# Multi-Modal Data Annotation Portfolio

A showcase of hands-on data labeling and quality assurance projects completed using **Label Studio** across NLP, Computer Vision, Audio, and Video modalities.

## Projects Included

### 1. Natural Language Processing (NLP)
* **Named Entity Recognition (NER):** Entity extraction (`name entity..png`)
* **Sentiment Analysis:** Text classification (`sentiment analysis.png`)
* **Intent Practice:** Multi-class intent taxonomy tagging

### 2. Computer Vision & Video
* **Semantic Segmentation:** Multi-class road scene polygon labeling (`semantic_segmentation_road_scene.png`)
* **Instance Segmentation:** Distinct object mask boundaries (`vision instance segmentation .png`)
* **Video Tracking:** Bounding box tracking across sequential frames (`video tracking.png`)

### 3. Audio Processing
* **Audio Transcription & Segmentation:** Soundwave timestamping and transcription verification (`audio transcription and segmentation.png`)

## Data & Exports
Includes raw `.json` export datasets generated directly from Label Studio alongside workspace screenshots for visual proof.
